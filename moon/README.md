# 站在月球上 · 陶拉斯-利特罗谷

`szx-and-szy.com/moon/`

第一人称月面体验。太阳与地球的位置、地球的视直径与相位，全部由真实天文算法在页面内现算，不是画上去的。

纯静态，无构建、无外部 CDN：`three.module.min.js` 与 three.js 官方后处理模块（`EffectComposer` / `UnrealBloomPass` / `FXAAShader` / `OutputPass`）都已放进 `vendor/`，地球纹理在 `assets/`，月壤贴图运行时用 Canvas 生成。

## 画质是怎么做出来的

不是靠堆贴图，分三层：

**一、材质层：程序化月壤（GLSL）**
月壤贴图按 11 m 周期平铺，再长也会有重复格。所以在 `MeshStandardMaterial` 上用 `onBeforeCompile` 注入了一段 GLSL：以**世界坐标**做 3D 值噪声，两层分别调制反照率（0.9 / 5.2 周期）和细节法线（11 周期）。世界坐标天然无重复，等于给地面加了一层无限分辨率、永不平铺的细节。

代价是逐像素 hash，所以按距离分支：反照率细节 120 m 外直接跳过，法线细节 42 m 外不计算。远处既不产生走样白点，也不浪费算力。

**二、几何层**
岩石从 `IcosahedronGeometry` 换成 `SphereGeometry` + 顶点扰动。前者是非索引几何，`computeVertexNormals` 只会给平面法线，近距离就是一堆三角面片；球体是索引几何，扰动后法线是平滑的，形状仍不规则。

**三、镜头层：后处理**
- `UnrealBloomPass`：阈值 0.90，只让太阳级别的亮度溢出，月壤本身不发光（半分辨率，省一半开销）
- `FXAAShader`：抗锯齿
- 自定义 `FilmShader`：胶片颗粒 + 暗角，模拟 Apollo 用的 70 mm 胶片与广角镜
- `OutputPass`：必须放在最后。`EffectComposer` 的 render target 保持线性空间，色调映射与 sRGB 转换只在直接渲染到屏幕时自动发生，漏掉它整幅画面会压暗一大截


## 这一版改了什么（观感重做）

**一、反射模型换成 Hapke（最关键的一步）**

原来用 Lambert，那是错的。月壤有强烈的后向散射，照片里最反直觉的特征——**斜视远处的地面反而更亮**——Lambert 永远算不出来，因为它只和入射角有关，与你从哪个角度看无关。

现在用 Hapke 1981 形式：

```
f_r = w/(4π) · 1/(μ0+μ) · { [1+B(g)]·P(g) + H(μ0)H(μ) − 1 }
```

其中 `H` 是 Chandrasekhar 函数（管多次散射）、`P` 是单粒子相函数、`B` 是冲效应项。`1/(μ0+μ)` 就是 Lommel-Seeliger 项，它让掠射方向变亮。参数取 `w = 0.32`、`h = 0.06`（月壤常用值），实现为对 `MeshStandardMaterial` 的 `directDiffuse` 做比值修正，阴影与地表反照率全部保留。

这一步和 NASA JPL 的月面巡视器仿真、ESA 的月壤材质项目做法一致——两者都明确说标准的 Lambert/BSDF 不够用。

**二、月壤贴图按实测坡度重做**

先把事实核对清楚。真实月壤的粒径分布是**极差分选**的：中值 60–90 μm，80 wt% < 250 μm，但 **20 wt% 粗于 1 mm、10 wt% 粗于 2 mm**。表面形态上，未扰动月壤在毫米–厘米尺度是 *visibly rough, hummocky*，有大量 clods 和 clumps（Helfenstein & Shepard 1999 用 Apollo 近距立体相机反演出 RMS 坡度 15–29° @ 0.85 mm、6–24° @ 8.5 mm；LRO Diviner 结果一致）。宇航员脚印把表面压平到毫米级，正说明原始状态是粗糙的。

所以贴图不是「平滑粉尘 + 稀疏颗粒」，而是：
- 高度场用**物理单位（毫米）**生成，法线直接由 `dh/dx` 得出，斜率就是真实坡度；
- 五层结构：亚毫米尘基底、微陨石「雨点坑」、1–8 mm 碎屑、1–5 cm 土块、逐颗粒棱角噪声；
- 覆盖率刻意做成**不均匀**——大片尘面之间夹杂成团的碎屑与土块。

**三、地形**

- 谷底大起伏从 7.5 m 降到 3.8 m，11 m / 4 m 两层降到 0.22 / 0.06——原来的振幅让地面像沙丘；
- 补了近场微型坑（0.3–2.8 m 半径），否则脚下是平的；
- 地面网格 1.25 m → 0.75 m 一格；
- 中景与远景改成**同一圈角度分段 + 同一接缝半径**，网格水密。之前 mid 到 2400 m、far 从 2300 m 起，中间 100 m 重叠，粗网格的弦高误差会把远景点顶出近景，产生一片白色薄板。

**四、曝光按实拍照片标定**

用 Canvas 统计画面下部地面的亮度分布，和 AS11-40-5874 的纯地面区域对齐：

| | 均值 | p10 | p50 | p90 | p99 |
|---|---|---|---|---|---|
| 本页 | 78 | 51 | 74 | 114 | 146 |
| 阿波罗照片 | 72 | 22 | 72 | 127 | 156 |

p50 与 p99 基本重合。p10 偏高是因为照片里有大量脚印与岩石的深阴影，而这里是未扰动地面。

**五、超采样**

`renderer.setPixelRatio(min(dpr × 1.4, 2.6))`。锯齿是「像游戏」最大的破绽之一，超采样比 FXAA 干净得多。桌面临时可用 `?ss=1` 关掉看性能。

## 性能

后处理是实打实的开销。三条退路，按需取：

- 正常打开：全开
- 觉得卡：URL 加 `?post=0` 关掉全部后处理（画面仍有点噪，但快很多）
- 只想去掉程序化细节：`?detail=0`
- 页面自己也会判断：开跑 4 秒后若帧率低于 26，自动关掉 bloom，保留 FXAA 与颗粒

触屏设备默认不开 bloom。

## 谁在算、算得准不准

天体位置由 `js/ephemeris.js` 计算，算法与误差：

- **月球黄道坐标**：Meeus《Astronomical Algorithms》第 47 章周期项截断，经度取 48 项、纬度 21 项、距离 12 项。精度约 0.01°（对应月面约 300 m 的位置偏差）
- **太阳位置**：Meeus 第 25 章低精度公式，精度约 0.01°
- **月球定向**：IAU 2009 月固坐标系（α0 / δ0 / W 的线性项）。天平动的周期项未纳入，因此亚地点方位误差在 ±0.05° 量级
- **本地地平坐标**：由月固系方向经站点经纬度换算出高度角/方位角，这一步是精确变换，无近似

这些值只在开场卡片上给出一次。进画面后 HUD 只剩左上角的站点与时刻，其余全部让给画面。

1972-12-11 19:54:57 UTC、20.1908°N / 30.7717°E 下的计算结果：

- 太阳高度 **13.85°**、方位 95.2°、视直径 0.542°
- 地球高度 **48.50°**、方位 249.0°、视直径 **1.873°**、照亮 **69.9%**
- 月地距离 389,806 km

阿波罗 17 号着陆时的实际太阳高度约 13–14°、方位在东偏南，与之吻合。

## 哪些是真数据，哪些是近似

真实：

- 站点经纬度、着陆时刻
- 太阳/地球的地平坐标、地球视直径与相位、月地距离、太阳视直径
- 重力 1.62 m/s²、眼高 1.7 m、地平线距离（由月球半径算出，2.43 km）
- 无大气带来的纯黑天空、硬阴影
- 太阳高度 13.85° 时，东侧山脊的仰角压到 8.65°，太阳位于山脊之上——这是按阿波罗 17 号照片里 East Massif 的实际仰角调的
- 地球纹理为 NASA 可见光全球反照率图（2048×1024）

近似，请注意：

- **地形是程序化生成的**，不是 LRO 高程栅格。坡度量级、谷底与山体高差参照阿波罗 17 号地形图，但具体起伏不对应真实坐标
- 山体加了 260 m 尺度的沟壑扰动，原先只有 900 m 一层，远看像光滑沙丘
- **环坑**：Camelot、Shorty、Van Serg、Sherlock 等名字取自阿波罗 17 号地质图，中心位置做了约 100 m 量级的取整
- **地球的旋转朝向**未按真实时刻对齐（只有位置、视直径、相位是准的）。地球在画面上只有约 27 px，朝向上看不出差别
- **星空**是装饰性的，压到近乎不可见（月球白昼看不到恒星，阿波罗照片里天空是纯黑）
- **地球反照光**用一层极弱的半球光近似。月壤在背对太阳时有后向散射，Lambert 表达不了，所以背光侧仍比真实照片暗
- 月壤的**后向散射（冲日效应）未建模**，用的是标准 Lambert 漫反射，所以背对太阳看地面会比真实照片暗
- 岩石用 `receiveShadow = false`：2048 阴影图覆盖 180 m（约 8.8 cm/texel），0.2–1.4 m 的岩石只有几个 texel，自阴影精度不足会把整块压成全黑。代价是岩石之间不会互相投影
- 逆光看岩石是黑色剪影，这不是 bug——低太阳角下看到的是背光面，阿波罗照片里同样如此

## 操作

- 桌面：点击画面锁定鼠标，WASD 移动（统一 2.6 m/s），空格跳（跳高约 1.1 m，滞空约 2.3 s），**E 看地球，Q 看太阳**，Esc 释放鼠标
- 太阳与地球相隔约 154°，广角下不可能同框，只能按键切换
- 开场视线取方位 60° 的侧光方向：正对地球会背光，地面全黑
- 触屏：左半屏虚拟摇杆移动，右半屏拖动看向，右下角按钮跳
- 没有单独的「快走」档，全程按小跑速度走（阿波罗 17 号实测月面平均行走约 1.4 m/s，小跑 2.5–3 m/s）

## 改站点或改时间

编辑 `js/app.js` 顶部的 `SITE`：

```js
const SITE = {
  name: '陶拉斯-利特罗谷',
  lat: 20.1908,
  lon: 30.7717,
  date: new Date(Date.UTC(1972, 11, 11, 19, 54, 57)),
};
```

其余数值会自动重算，HUD 同步更新。

注意：月面上看地球，位置由站点经纬度决定，**地球基本不动**（只有天平动带来 ±8° 的缓慢摆动），不会像绕月轨道上那样"升起"。想看"地出"，得换到轨道视角——那是另一件事。
