# 站在月球上 · 陶拉斯-利特罗谷

`space.szx-and-szy.com/moon/`

第一人称月面体验。太阳与地球的位置、地球的视直径与相位，全部由真实天文算法在页面内现算，不是画上去的。

纯静态，无构建、无外部 CDN：`three.module.min.js` 已放进 `vendor/`，地球纹理在 `assets/`，其余贴图运行时用 Canvas 生成。

## 谁在算、算得准不准

天体位置由 `js/ephemeris.js` 计算，算法与误差：

- **月球黄道坐标**：Meeus《Astronomical Algorithms》第 47 章周期项截断，经度取 48 项、纬度 21 项、距离 12 项。精度约 0.01°（对应月面约 300 m 的位置偏差）
- **太阳位置**：Meeus 第 25 章低精度公式，精度约 0.01°
- **月球定向**：IAU 2009 月固坐标系（α0 / δ0 / W 的线性项）。天平动的周期项未纳入，因此亚地点方位误差在 ±0.05° 量级
- **本地地平坐标**：由月固系方向经站点经纬度换算出高度角/方位角，这一步是精确变换，无近似

页面右上角显示的就是这些算出来的值，可直接与星历软件对照。

1972-12-11 19:54:57 UTC、20.1908°N / 30.7717°E 下的计算结果：

- 太阳高度 **13.85°**、方位 95.2°、视直径 0.542°
- 地球高度 **48.50°**、方位 249.0°、视直径 **1.873°**、照亮 **69.9%**
- 月地距离 389,806 km

阿波罗 17 号着陆时的实际太阳高度约 13–14°、方位在东偏南，与之吻合。

## 哪些是真数据，哪些是近似

真实：

- 站点经纬度、着陆时刻
- 太阳/地球的地平坐标、地球视直径与相位、月地距离、太阳视直径
- 重力 1.62 m/s²、眼高 1.7 m、地平线距离（由月球半径算出，2.43 km）
- 无大气带来的纯黑天空、零环境光、硬阴影
- 地球纹理为 NASA 可见光全球反照率图（2048×1024）

近似，请注意：

- **地形是程序化生成的**，不是 LRO 高程栅格。坡度量级、谷底与山体高差参照阿波罗 17 号地形图，但具体起伏不对应真实坐标
- **环坑**：Camelot、Shorty、Van Serg、Sherlock 等名字取自阿波罗 17 号地质图，中心位置做了约 100 m 量级的取整
- **地球的旋转朝向**未按真实时刻对齐（只有位置、视直径、相位是准的）。地球在画面上只有约 27 px，朝向上看不出差别
- **星空**是装饰性的。月球白昼实际上几乎看不到恒星，这里保留了极淡的一层作为空间感
- 月壤的**后向散射（冲日效应）未建模**，用的是标准 Lambert 漫反射，所以背对太阳看地面会比真实照片略暗

## 操作

- 桌面：点击画面锁定鼠标，WASD 行走，Shift 快走，空格跳（跳高约 1.1 m，滞空约 2.3 s），E 看向地球，Esc 释放鼠标
- 触屏：左半屏虚拟摇杆移动，右半屏拖动看向，右下角按钮跳

## 改站点或改时间

编辑 `js/app.js` 顶部的 `SITE`：

```js
const SITE = {
  name: '陶拉斯-利特罗谷',
  lat: 20.1908,
  lon: 30.7717,
  date: new Date(Date.UTC(1972, 11, 11, 19, 54, 57)),
};
```

其余数值会自动重算，HUD 同步更新。

注意：月面上看地球，位置由站点经纬度决定，**地球基本不动**（只有天平动带来 ±8° 的缓慢摆动），不会像绕月轨道上那样"升起"。想看"地出"，得换到轨道视角——那是另一件事。
